## What to build

WhatsApp inquiries enter the shared sales workflow and supported manual app replies hand control to the salesperson.

## Acceptance criteria

- [ ] Authenticate and deduplicate scoped Meta events, associate messages with the correct buyer/Opportunity and preserve provider identities.
- [ ] Apply the same approved knowledge, qualification and conversion goal without collapsing unrelated purchasing needs or Business context.
- [ ] Reflect supported coexistence/manual app activity as Opportunity takeover; provide an obvious escalation route and keep unrelated work active.
- [ ] Surface missing reply visibility or unsupported event coverage and pause affected automation instead of claiming complete synchronization.
- [ ] Complete the relevant persistence, application/API and UI path; verify observable state and outbound effects at the primary application seam with real internal persistence, deterministic providers and a controlled clock.
- [ ] Enforce actor/Business scope for the reads, writes, provider events and queued work touched here; validate external data and keep public errors and diagnostics safe.
- [ ] Apply the accepted discovery/handler/worker boundaries and frontend stack/design skills. After final code edits, run Prettier and lint, fix failures and report the results.
