## What to build

A Business reviews discovery quality, engagement, conversion outcomes, communication health and human effort without inflated counts.

## Acceptance criteria

- [ ] Report fit/source coverage, deduplication, named-buyer/contact accuracy, request freshness and discovery cost using explainable metric denominators and provenance.
- [ ] Keep evidence-backed matches, contactable prospects, direct engagement, RFQs, issued quotes, requested/confirmed/attended appointments and sales distinct.
- [ ] Show response/qualification coverage, opt-outs, complaints, sender pauses, handoffs, next actions and recorded human effort across supported channels.
- [ ] Apply Business/role isolation and honest unavailable/estimated/stale data labels; customer-paid Meta usage stays separate from platform allowances and operator costs.
- [ ] Complete the relevant persistence, application/API and UI path; verify observable state and outbound effects at the primary application seam with real internal persistence, deterministic providers and a controlled clock.
- [ ] Enforce actor/Business scope for the reads, writes, provider events and queued work touched here; validate external data and keep public errors and diagnostics safe.
- [ ] Apply the accepted discovery/handler/worker boundaries and frontend stack/design skills. After final code edits, run Prettier and lint, fix failures and report the results.
