# Share TypeScript across the web application and asynchronous workers

The product combines a web sales application with MCP-enabled discovery and durable follow-ups. Use TypeScript for the web application, API, and workers, sharing business modules while separating request handling from asynchronous execution; Python remains available for a demonstrated dependency or workload advantage. This favors one language for a solo founder over an immediate TypeScript/Python split, and MCP support does not require that split.
