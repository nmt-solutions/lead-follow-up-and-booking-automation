# Use one interactive PostgreSQL access and schema stack

Use Drizzle ORM and Drizzle Kit with node-postgres for the Next.js application and Trigger workers, preserving interactive transaction support on the selected Node runtimes. Runtime traffic uses Neon's pooled endpoint, while schema updates use a direct owner connection; Business context and protected queries belong in the same transaction under a restricted database role. At the user's request, use `pnpm db-push` (`drizzle-kit push`) for schema changes without generated or applied migration files; keep RLS policies in the schema and reapply their conditions, grants, forced RLS and deferred constraints through an idempotent security step because the pinned Drizzle push cannot preserve all of them.
