# Use customer-billed Meta Cloud API

Use Meta WhatsApp Cloud API directly through the Tech Provider route, with each Business controlling its account/number and paying Meta for its messaging usage. Our subscription covers our automation service and allowances, while the customer-paid Meta charge is disclosed separately and excluded from the operator's own spend ledger. This accepts our onboarding/integration/approval responsibilities and separate billing in exchange for avoiding an initial paid BSP or credit-line arrangement; coexistence and production access remain subject to the supported account path.
